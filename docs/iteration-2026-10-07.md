# 2026-10-07 迭代记录

本轮围绕真实验收中暴露的输出可读性、内部完成节点、首屏依赖与首次远端 CI 失败进行优化。

## 执行输出与完成状态

Claude Code 的持久化 stdout 原先直接展示 JSON。现在仅解析完整 JSON 行，按原顺序显示会话初始化、准备与 hook、模型文字回复、工具名称和文字结果，保留可展开的完整原始摘要；非 Claude 引擎、普通文字、无法识别的 JSON 仍原样展示。未知或截断片段不会生成猜测结果，HTML 始终作为文字，不创建链接、图片或脚本。

上游 stdout/stderr 各最多 2048 字符。这不是实时流或完整会话记录。上次真实运行的摘要只有启动记录，因此界面明确提示没有模型文字回复，最终交付查看产物。模型文字或 result 事件不决定任务状态。

成功任务的内部 `__complete` 当前节点显示“执行已结束”。默认检查的 attempt 仍优先选择工作流业务节点，避免选到无输出的内部收尾 attempt；API 与原始状态不变。

## 入口依赖

改用 Ant Design ESM locale，移除未使用的 App provider，并将 BusinessModal、DangerConfirm 从基础组件模块分离。构建入口由 701.05 kB（gzip 226.92 kB）降至 638.08 kB（gzip 208.73 kB），原始入口缩小约 9%。弹窗独立 chunk 为 68.39 kB；业务页仍会按需加载它，因此不能把入口下降视作所有路由总下载量下降。

入口仍超过 Vite 500 kB 警告阈值，未隐藏警告。下一步性能工作需结合实际访问路径和加载测量，避免仅重新分配 chunk 来美化数字。

## CI 修复

[首次远端检查](https://github.com/wangyichen666/auto-dev-intranet/actions/runs/37459192306)中，两个表单测试超过默认 5 秒。测试脚本此前忽略 `--runInBand` 后仍按文件并行，低并发 runner 的组件初始化产生竞争。现在显式转换为 Vitest 单 worker、关闭文件并行；没有调大超时，保留原断言。
