# 界面决策

- Surface：命令型内网控制台；操作者扫描任务状态、定位失败并执行可用控制。
- P1：任务表格或执行轨道；P2：状态筛选和工作流元数据；P3：attempt、事件和产物；Action：新建或当前可用控制。
- 内容事实：API 返回的真实记录。首次空数据、未配置与服务不可用均独立呈现。仅测试 Gateway 使用固定样本。
- 桌面：`[窄导航][页头 / 筛选 / 紧凑数据区]`；详情：`[阶段与 attempt 65%][产物 / 运行信息 / 事件 35%]`。
- 移动：`[菜单 / 上下文][页头 / 操作][筛选][任务条目]`；详情在 1100px 及以下通过 tabs 切换过程、产物与信息，避免侧栏占位后压窄元数据。
- System：冷中性背景、白面板、蓝命令色与语义状态色；系统中文字体，ID/源码等宽；4px 节奏；4–8px 圆角；浮层才有阴影；SOFA icons。
- Signature：冻结工作流的编号阶段轨道；真实节点与 attempt 关联，突出执行边界。
- Cliche budget：0；不使用营销图、假指标或装饰性遥测。
- Failure risks：详情双栏在中屏压缩，移动操作/错误长文案溢出；用 390/768/1024/1440/1920/2560 的浏览器截图和 scrollWidth 检查。

- 输出检查区：先列出完整 Claude 事件中的会话、回复、工具名称与结果，原始摘要默认折叠、可用键盘展开；stderr 独立呈现。上游每路摘要限 2048 字符，启动事件不能证明模型已有文字回复，截断或未知片段须明确提示并保留原文。
- 完成节点：仅已成功且当前节点为 `__complete` 的运行显示“执行已结束”；保持原始状态和 DTO，不将其他节点或结果文字推断成成功。
- 依赖边界：基础组件不静态引入弹窗；弹窗与对应业务页一同加载。Ant Design locale 使用 ESM，不通过提高构建警告阈值掩盖入口体积。
